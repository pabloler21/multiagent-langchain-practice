# Gestion de Proveedores, Facturas de Proveedores y Formularios Fiscales

## 1. Alta de Nuevos Proveedores (Vendor Onboarding)
- Todo nuevo proveedor debe completar el formulario de registro adjuntando:
  - Constancia de inscripcion impositiva (W-9 para US / Constancia de CUIT/RUT para LATAM).
  - Certificado de cuenta bancaria oficial emitida por el banco.
  - Formulario de no conflicto de intereses.
- Plazo de procesamiento de alta de proveedor: 5 dias habiles.

## 2. Calendario de Pago a Proveedores
- Pagos a proveedores se emiten exclusivamente los dias jueves de cada semana via transferencia bancaria ACH / SWIFT.
